How to Generate GitHub Token

A free GitHub Personal Access Token allows you to save updates directly from this admin panel to the website repository without needing a paid server:

  1. Open github.com/settings/tokens/new
  2. Note: Type Tanur Heritage Admin
  3. Expiration: Select No expiration (or 90 days)
  4. Scopes: Check the box [x] repo (Full control of repositories)
  5. Click the green Generate token button at the bottom
  6. Copy the generated token (starts with ghp_...) and paste it here!
